# Specifications

This directory contains durable, integrated architecture and product contracts.

- `CONTEXT.md` defines canonical domain vocabulary.
- `docs/specs/v3-configuration-architecture.md` defines the accepted v3 runtime and configuration architecture.
- `docs/specs/v3-dependency-version-strategy.md` defines the supported dependency contract and compatibility evidence.
- `docs/specs/release-verification.md` defines the release gate, publication, and registry-health contract.
- GitHub Issues track implementation slices, blocking edges, and progress.

Specifications should remain independent of a particular agent workflow. Do not store session notes, step-by-step implementation plans, commit scripts, or volatile file-and-line instructions here.
