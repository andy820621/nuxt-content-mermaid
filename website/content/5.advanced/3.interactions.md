# Interactions

The built-in renderer provides source copying, browser fullscreen, an expand overlay, and zoom/pan controls. A successfully resolved [Custom Renderer](/advanced/custom-rendering) replaces all of them, so this page applies only to the built-in renderer.

## Choose visible toolbar controls

The toolbar appears above each built-in diagram. Its title and controls are enabled by default:

```ts
export default defineNuxtConfig({
  contentMermaid: {
    toolbar: {
      title: 'Architecture',
      fontSize: '14px',
      fullscreenToolbarScale: 1.25,
      buttons: {
        copy: true,
        fullscreen: true,
        expand: true,
      },
      labels: {
        copy: 'Copy source',
        copied: 'Source copied',
        copyFailed: 'Copy failed',
        resetZoom: 'Reset view',
      },
    },
  },
})
```

`copy` copies Mermaid source. After an attempt, its button temporarily uses the configured `copied` or `copyFailed` label; the renderer first uses the Clipboard API and then attempts the browser's legacy copy fallback. `fullscreen` is displayed only when the browser supports the Fullscreen API. `expand` opens the in-page overlay.

Set a button to `false` to hide it. Hiding the expand button does not disable opening an overlay by clicking a diagram; control that separately with `expand.invokeOpenOn.diagramClick`.

## Customize control labels

Use `toolbar.labels` to localize or rename the built-in controls. Set application-wide defaults in `nuxt.config.ts`:

```ts
export default defineNuxtConfig({
  contentMermaid: {
    toolbar: {
      labels: {
        copy: 'Copy source',
        copied: 'Source copied',
        copyFailed: 'Copy failed',
        expand: 'Expand diagram',
        collapse: 'Collapse diagram',
        minimize: 'Minimize diagram',
        enterFullscreen: 'Enter fullscreen',
        exitFullscreen: 'Exit fullscreen',
        zoomIn: 'Zoom in',
        zoomOut: 'Zoom out',
        resetZoom: 'Reset zoom',
      },
    },
  },
})
```

The object is a partial override: configure only the labels you want to change. Omitted labels keep their defaults, while an empty string is preserved as an explicit value. Each resolved label is reused as visible text, `title`, and `aria-label` wherever that control exposes those surfaces.

A Mermaid fence can override labels for one diagram without changing the application defaults:

````md
```mermaid
---
toolbar:
  labels:
    copy: Copy this diagram
    copied: Diagram copied
    resetZoom: Reset diagram view
---
graph TD
  A --> B
```
````

See [Toolbar configuration](/configuration#toolbar) for every label key, type, default, and currently reserved option.

## Configure opening and closing

`expand` is enabled by default. Its close controls are independently configurable:

```ts
export default defineNuxtConfig({
  contentMermaid: {
    expand: {
      margin: 24,
      invokeOpenOn: {
        diagramClick: true,
      },
      invokeCloseOn: {
        esc: true,
        wheel: true,
        swipe: true,
        overlayClick: true,
        closeButtonClick: true,
      },
    },
  },
})
```

`margin` keeps pixels around the expanded SVG. Set `expand: false` to disable the feature entirely. See [Configuration](/configuration#expand) for the boolean-preset and object-patch distinction.

See [Expand configuration](/configuration#expand) for the complete option paths, defaults, and effects.

The browser fullscreen control exits through the browser's normal fullscreen behavior. It does not use the expand-overlay close policy.

## Zoom and pan a large diagram

Fullscreen and the expanded overlay show zoom-out, zoom-in, percentage, and reset controls. The same mappings work in either view:

| Input | Action |
| --- | --- |
| Zoom controls | Zoom out, zoom in, or reset. |
| `Ctrl` + wheel on Windows/Linux, or `⌘` + wheel on macOS | Zoom at the pointer. |
| `+` / `=` | Zoom in. |
| `-` / `_` | Zoom out. |
| `0` | Reset zoom and pan. |
| Arrow keys | Pan the diagram. |
| Hold Space and drag with a mouse | Pan the diagram. |
| One-finger touch drag | Pan the diagram. |
| Two-finger pinch | Zoom the diagram. |

In the expand overlay, an unmodified wheel over the diagram does not zoom; it displays a one-time hint to use `Ctrl` or `⌘` plus scrolling. A wheel over the overlay background follows the configured close behavior. A pinch is treated as a diagram manipulation, not a swipe-to-close gesture.

## Keep controls understandable and accessible

### Built-in controls

The built-in toolbar controls always use native `<button>` elements with corresponding accessible labels, covering:

- Copy
- Enter/Exit fullscreen
- Expand/Collapse diagram
- Zoom In/Out
- Reset Zoom
- Minimize diagram

Labels can be customized through `toolbar.labels`; the resolved value is applied as visible text, `title`, and `aria-label` where applicable.

### Keyboard operation

All controls can be operated via keyboard. Zoom shortcuts are also available while a diagram is in the expanded view or fullscreen mode.

### Focus management

- On expand, focus moves to the close button; if `closeButtonClick` is disabled, focus moves to the dialog itself instead.
- While in the expanded view, Tab and Shift+Tab keep focus trapped within the overlay's toolbar.
- On entering fullscreen, focus moves to the exit fullscreen button.
- After closing the expanded view or exiting fullscreen:
  - If the toolbar control that originally triggered it still exists, focus returns to that control.
  - If the diagram or control has been removed, focus restoration is skipped.

::callout{variant="warning" title="Accessibility reminder"}
When you disable a close path, make sure at least one other reachable close path remains available. If `esc`, `overlayClick`, and `closeButtonClick` are all disabled at the same time, users may have no obvious way to exit the expanded view.

If you replace the built-in renderer with a custom component, reimplement equivalent labels, keyboard access, focus management, and touch interactions to preserve the same level of accessibility.
::
