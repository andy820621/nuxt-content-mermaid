# 設定

請在 `nuxt.config.ts` 的 `contentMermaid` 下設定套件擁有的行為。Mermaid 自身的圖表 schema 仍是 Mermaid 的契約；本頁只說明本模組擁有的設定。

```ts
export default defineNuxtConfig({
  contentMermaid: {
    loader: { lazy: true },
    theme: { light: 'default', dark: 'dark' },
  },
})
```

## 選擇設定的位置

`enabled` 是 Module Activation：Nuxt 在模組啟動時讀取它，並非公開的執行階段設定。其他所有可序列化選項也可透過 `runtimeConfig.public.contentMermaid` 提供；此 transport 只接受嚴格純資料，並且每個應用程式執行個體只解析一次。

套件擁有的設定層採用 property-presence merge：缺少屬性才會 fallback；已存在的 `false`、`null`、`0`、空字串、空陣列或非物件值，都會取代較低優先層的值。

## 一般選項

| 選項 | 類型 | 預設值 | 用途 |
| --- | --- | --- | --- |
| `enabled` | `boolean` | `true` | 在 Nuxt 設定期間啟用 Module Activation、Markdown 轉換與 runtime integration。 |
| `debug` | `boolean` | `false` | 使用利於除錯的 Mermaid 錯誤預設值，並以更多細節回報渲染失敗。 |

## 載入與 Mermaid 初始化

| 選項 | 類型 | 預設值 | 用途 |
| --- | --- | --- | --- |
| `loader.lazy` | `boolean` 或 `{ threshold?: number }` | `true` | 延後初次渲染，直到圖表進入 viewport。設為 `false` 則在 mount 時渲染。 |
| `loader.lazy.threshold` | `number` | 省略時為 `0.1` | Lazy rendering 的 `IntersectionObserver` 可見性門檻。 |
| `loader.init` | 純資料 Mermaid 設定 | 見下方 | 專案層級的 Mermaid 初始化資料。 |

`loader.init` baseline 如下：

```ts
{
  startOnLoad: false,
  theme: 'default',
  fontFamily: 'Arial, sans-serif, 微軟正黑體',
  securityLevel: 'strict',
}
```

除非在 `loader.init` 明確設定，`debug: false` 會解析為 `logLevel: 5` 與 `suppressErrorRendering: true`；`debug: true` 會解析為 `logLevel: 1` 與 `suppressErrorRendering: false`。明確設定的值永遠優先。

## 設定主題預設值

| 選項 | 類型 | 預設值 | 用途 |
| --- | --- | --- | --- |
| `theme.light` | Mermaid 主題名稱 | `'default'` | 由淺色 color mode 或保留的手動 `'light'` 策略選用的主題。 |
| `theme.dark` | Mermaid 主題名稱 | `'dark'` | 由深色 color mode 或保留的手動 `'dark'` 策略選用的主題。 |
| `theme.useColorModeTheme` | `boolean` | 省略 | 已棄用的相容鍵，沒有作用。 |

手動主題控制、主題優先順序、與 color-mode 共存及 CSS hooks，請參閱[主題與樣式](/zh/advanced/themes-and-styling)。

## 設定元件替換

| 選項 | 類型 | 預設值 | 用途 |
| --- | --- | --- | --- |
| `components.renderer` | `string` | 省略 | 可用來取代內建 renderer 的應用程式元件名稱。 |
| `components.spinner` | `string` | 省略 | 提供給內建 renderer 與已解析 custom renderer 的應用程式載入元件名稱。 |
| `components.error` | `string` | 省略 | 內建 Mermaid 渲染失敗時使用的錯誤元件名稱。 |

元件名稱會從 `~/components` 下的檔案解析。找不到或無法載入 renderer candidate 時，會回到內建 renderer；成功解析的 custom renderer 則自行擁有載入與錯誤體驗。請參閱[自訂渲染](/zh/advanced/custom-rendering)。

## 設定工具列

| 選項 | 類型 | 預設值 | 用途 |
| --- | --- | --- | --- |
| `toolbar.title` | `string` | `'mermaid'` | 工具列預設標題。 |
| `toolbar.fontSize` | `string` 或 `number` | `'14px'` | 工具列文字大小；數字視為像素。 |
| `toolbar.fullscreenToolbarScale` | `number` | `1.25` | 全螢幕時工具列文字與圖示的倍率。 |
| `toolbar.buttons.copy` | `boolean` | `true` | 顯示複製原始碼控制項。 |
| `toolbar.buttons.fullscreen` | `boolean` | `true` | 瀏覽器支援時顯示全螢幕控制項。 |
| `toolbar.buttons.expand` | `boolean` | `true` | 顯示展開 overlay 控制項。 |

## 設定展開行為

`expand` 有兩種刻意不同的形式：

| 形式 | 含義 |
| --- | --- |
| `expand: true` | 將較低優先層的 expand 狀態重設為套件預設值，且 `enabled: true`。 |
| `expand: false` | 將較低優先層的 expand 狀態重設為套件預設值，且 `enabled: false`。 |
| `expand: { ... }` | 逐一屬性 patch 較低優先層的狀態。省略 `enabled` 會保留啟用狀態。 |

若較低層是 `expand: false` preset，物件不會重新啟用它，除非明確設定 `enabled: true`：

```ts
export default defineNuxtConfig({
  contentMermaid: {
    expand: { enabled: true, margin: 24 },
  },
})
```

| 選項 | 類型 | 預設值 | 用途 |
| --- | --- | --- | --- |
| `expand.enabled` | `boolean` | `true` | 啟用展開互動。 |
| `expand.margin` | `number` | `0` | 展開圖表周圍的像素空間。 |
| `expand.invokeOpenOn.diagramClick` | `boolean` | `true` | 點擊圖表時開啟 overlay。 |
| `expand.invokeCloseOn.esc` | `boolean` | `true` | 允許 Escape 關閉 overlay。 |
| `expand.invokeCloseOn.wheel` | `boolean` | `true` | 允許在 overlay 上滾動時關閉。 |
| `expand.invokeCloseOn.swipe` | `boolean` | `true` | 允許單指滑動關閉。 |
| `expand.invokeCloseOn.overlayClick` | `boolean` | `true` | 允許點擊 overlay 背景關閉。 |
| `expand.invokeCloseOn.closeButtonClick` | `boolean` | `true` | 顯示並啟用關閉控制項。 |

完整的控制項與手勢對照請參閱[互動](/zh/advanced/interactions)。

## 將 Mermaid 擁有的設定留給 Mermaid

`loader.init`、Page Mermaid Config、Direct Mermaid Config、Mermaid YAML frontmatter 與 directives 都可攜帶 Mermaid 設定。本模組會保留這個開放 payload，但不會重新定義 Mermaid 的選項、主題、安全性設定或 directive 語意。該 schema 請參閱官方 [Mermaid 設定文件](https://mermaid.js.org/config/configuration.html)與 [directive 文件](https://mermaid.js.org/config/directives.html)。
