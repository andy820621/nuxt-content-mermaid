# 設定

請在 `nuxt.config.ts` 的 `contentMermaid` 下設定套件擁有的行為。Mermaid 自身的圖表結構描述（schema）仍是 Mermaid 的契約；本頁只說明本模組擁有的設定。

先區分兩種設定邊界：

- `contentMermaid` 控制模組與內建渲染器的應用程式預設值
- 頁面 `config`、元件 `config` 與 Mermaid 圍欄 (fence) 內的 frontmatter 則控制圖表本身。

`toolbar` 和 `expand` 是本模組的 UI 行為，不屬於 Mermaid 的 `config`。

```ts
export default defineNuxtConfig({
  contentMermaid: {
    loader: { lazy: true },
    theme: { light: 'default', dark: 'dark' },
  },
})
```

## 一般設定

`enabled` 是模組啟用（Module Activation）：Nuxt 在模組啟動時讀取它，並非公開的執行階段設定。
其餘可序列化選項可透過 `runtimeConfig.public.contentMermaid` 提供，此傳輸邊界（transport）只接受嚴格純資料，並在應用程式初始化時解析為一次性快照。

::callout{variant="warning" title="變更後需重新載入應用程式才會套用"}
本模組會在每個 Nuxt 應用程式實例初始化時，從 `runtimeConfig.public.contentMermaid` 建立一次**不可變快照**；
執行期間修改原始物件不會重新初始化 Mermaid，需重新建立或重新載入應用程式才會套用新設定。
::

套件擁有的設定層採用屬性存在合併（property-presence merge）：缺少屬性才會使用後備值；已存在的 `false`、`null`、`0`、空字串、空陣列或非物件值，都會取代較低優先層的值。

### 設定來源

| 來源 | 作用範圍 | 優先／覆寫規則 | 限制 |
| --- | --- | --- | --- |
| `contentMermaid` | Nuxt 建置期模組設定與應用程式預設 | 可由 `runtimeConfig.public.contentMermaid` 覆寫 | `enabled` 只能在建置期設定；其他值必須是可序列化資料 |
| `runtimeConfig.public.contentMermaid` | 整個 Nuxt 應用程式的 runtime 設定 | 以屬性存在合併覆寫模組預設 | 不接受 `enabled`；只接受嚴格純資料，且會建立一次設定快照 |
| Content 頁面 `config` | 同一頁的 Mermaid 圖表設定 | 與 runtime Mermaid 設定合併 | 必須在 collection schema 宣告，且只能包含純資料 |
| `<Mermaid :config="...">` | 單一 Vue 元件的 Mermaid 設定 | 與 runtime Mermaid 設定合併 | 可使用 direct config 支援的 client-only capability；不可同時提供 `pageConfig` |
| Mermaid 圍欄 (fence) frontmatter／directive | 單一圖表的原始碼設定 | 由 Mermaid 依自己的規則解析 | 不屬於本模組的 runtime options |

頁面 `config` 與元件 `config` 是兩種互斥的元件來源；它們不是可以同時傳入、再互相覆寫的兩層設定。單一圖表的工具列可另外使用 fence `toolbar` 或元件 `toolbar` 覆寫專案預設。

### 模組啟用與除錯

| 選項 | 類型 | 預設值 | 用途／限制 |
| --- | --- | --- | --- |
| `enabled` | `boolean` | `true` | 在 Nuxt 建置期間啟用模組、Markdown 轉換與執行階段整合；不能放入公開 runtime 設定。 |
| `debug` | `boolean` | `false` | 使用利於除錯的 Mermaid 錯誤預設值，並以更多細節回報渲染失敗。 |

## 載入與 Mermaid 初始化

| 選項 | 類型 | 預設值 | 用途／限制 |
| --- | --- | --- | --- |
| `loader.lazy` | `boolean` 或 `{ threshold?: number }` | `true` | 延後初次渲染，直到圖表進入可視區域；設為 `false` 則在掛載時渲染。 |
| `loader.lazy.threshold` | `number` | `0.1` | 延後渲染的 `IntersectionObserver` 可見性門檻。 |
| `loader.init` | 純資料 Mermaid 設定 | 見下方 | 專案層級的 Mermaid 初始化資料；不接受函式或其他 client-only capability。 |

`loader.init` 基準設定如下：

```ts
{
  startOnLoad: false,
  theme: 'default',
  fontFamily: 'Arial, sans-serif, 微軟正黑體',
  securityLevel: 'strict',
}
```

除非在 `loader.init` 明確設定，`debug: false` 會解析為 `logLevel: 5` 與 `suppressErrorRendering: true`；`debug: true` 會解析為 `logLevel: 1` 與 `suppressErrorRendering: false`。明確設定的值永遠優先。

## 主題

| 選項 | 類型 | 預設值 | 用途／限制 |
| --- | --- | --- | --- |
| `theme.light` | Mermaid 主題名稱 | `'default'` | 由淺色色彩模式或保留的手動 `'light'` 策略選用的主題。 |
| `theme.dark` | Mermaid 主題名稱 | `'dark'` | 由深色色彩模式或保留的手動 `'dark'` 策略選用的主題。 |
| `theme.useColorModeTheme` | `boolean` | 省略 | 已棄用的相容鍵，沒有作用。 |

手動主題控制、主題優先順序、與色彩模式共存及 CSS 樣式鉤點，請參閱[主題與樣式](/zh/advanced/themes-and-styling)。

## 自訂元件

| 選項 | 類型 | 預設值 | 用途／限制 |
| --- | --- | --- | --- |
| `components.renderer` | `string` | 省略 | 可用來取代內建渲染器的應用程式元件名稱。 |
| `components.spinner` | `string` | 省略 | 提供給內建渲染器與已解析自訂渲染器的應用程式載入元件名稱。 |
| `components.error` | `string` | 省略 | 內建 Mermaid 渲染失敗時使用的錯誤元件名稱。 |

元件名稱會從 `~/components` 下的檔案解析。找不到或無法載入渲染器候選項時，會回到內建渲染器；成功解析的自訂渲染器則自行擁有載入與錯誤體驗。請參閱[自訂渲染](/zh/advanced/custom-rendering)。

`components.spinner` 找不到時會記錄診斷訊息並使用套件內建的載入指示器；`components.error` 只套用於內建渲染器，不會注入已成功解析的自訂渲染器。

## 工具列

| 選項 | 類型 | 預設值 | 用途／限制 |
| --- | --- | --- | --- |
| `toolbar.title` | `string` | `'mermaid'` | 工具列預設標題；不是 Mermaid 的 `title` 中繼資料。 |
| `toolbar.fontSize` | `string` 或 `number` | `'14px'` | 工具列文字大小；數字視為像素。 |
| `toolbar.fullscreenToolbarScale` | `number` | `1.25` | 全螢幕時工具列文字與圖示的倍率。 |
| `toolbar.buttons.copy` | `boolean` | `true` | 顯示複製原始碼控制項。 |
| `toolbar.buttons.fullscreen` | `boolean` | `true` | 瀏覽器支援時顯示全螢幕控制項。 |
| `toolbar.buttons.expand` | `boolean` | `true` | 顯示展開覆蓋層控制項。 |
| `toolbar.labels.copy` | `string` | `'Copy'` | 複製控制項標籤。 |
| `toolbar.labels.copied` | `string` | `'Copied'` | 複製成功標籤。 |
| `toolbar.labels.copyFailed` | `string` | `'Copy failed'` | 複製失敗標籤。 |
| `toolbar.labels.expand` | `string` | `'Expand diagram'` | 開啟展開覆蓋層的標籤。 |
| `toolbar.labels.collapse` | `string` | `'Collapse diagram'` | 離開展開狀態的標籤。 |
| `toolbar.labels.minimize` | `string` | `'Minimize diagram'` | 關閉展開覆蓋層的標籤。 |
| `toolbar.labels.enterFullscreen` | `string` | `'Enter fullscreen'` | 進入瀏覽器全螢幕的標籤。 |
| `toolbar.labels.exitFullscreen` | `string` | `'Exit fullscreen'` | 離開瀏覽器全螢幕的標籤。 |
| `toolbar.labels.zoomIn` | `string` | `'Zoom In'` | 放大控制項標籤。 |
| `toolbar.labels.zoomOut` | `string` | `'Zoom Out'` | 縮小控制項標籤。 |
| `toolbar.labels.resetZoom` | `string` | `'Reset Zoom'` | 重設縮放控制項的標籤與可見文字。 |
| `toolbar.labels.downloadSvg` | `string` | `'Download SVG'` | 下載最後一次成功提交 SVG 的控制項標籤。 |

這些是全域工具列預設值。Markdown fence 可用 `toolbar`，Vue 元件可用 `:toolbar`，在單一圖表層級覆寫它們。標籤物件會逐一屬性合併，因此省略的標籤保留預設值；空字串是有效且明確的標籤，其他非字串值無效。內建渲染器會在存在的介面上一致地將解析後標籤用於可見文字、`title` 與 `aria-label`。

`toolbar.title` 是工具列標題，不是 Mermaid 的 `title` 中繼資料。下載控制項會將 `downloadSvg` 用作 `title` 與 `aria-label`；內建渲染器尚未產生可直接存取的成功 SVG 前，按鈕會保持停用。

## 展開

`expand` 接受 `boolean` 或物件兩種型別，且刻意賦予不同語意：`boolean` 的 `true`／`false` 各自對應不同的重設行為，物件則逐一屬性修補。

| 形式 | 含義 |
| --- | --- |
| `expand: true` | 將較低優先層的 expand 狀態重設為套件預設值，且 `enabled: true`。 |
| `expand: false` | 將較低優先層的 expand 狀態重設為套件預設值，且 `enabled: false`。 |
| `expand: { ... }` | 逐一屬性修補較低優先層的狀態。省略 `enabled` 會保留啟用狀態。 |

若較低層是 `expand: false` 預設組態，物件不會重新啟用它，除非明確設定 `enabled: true`：

```ts
export default defineNuxtConfig({
  contentMermaid: {
    expand: { enabled: true, margin: 24 },
  },
})
```

| 選項 | 類型 | 預設值 | 用途／限制 |
| --- | --- | --- | --- |
| `expand.enabled` | `boolean` | `true` | 啟用展開互動。 |
| `expand.margin` | `number` | `0` | 展開圖表周圍的像素空間。 |
| `expand.invokeOpenOn.diagramClick` | `boolean` | `true` | 點擊圖表時開啟覆蓋層。 |
| `expand.invokeCloseOn.esc` | `boolean` | `true` | 允許 Escape 關閉覆蓋層。 |
| `expand.invokeCloseOn.wheel` | `boolean` | `true` | 允許在覆蓋層上滾動時關閉。 |
| `expand.invokeCloseOn.swipe` | `boolean` | `true` | 允許單指滑動關閉。 |
| `expand.invokeCloseOn.overlayClick` | `boolean` | `true` | 允許點擊覆蓋層背景關閉。 |
| `expand.invokeCloseOn.closeButtonClick` | `boolean` | `true` | 顯示並啟用關閉控制項。 |

完整的控制項與手勢對照請參閱[互動](/zh/advanced/interactions)。

## Mermaid 負責的設定

`loader.init`、Page Mermaid Config、Direct Mermaid Config、Mermaid YAML 前置資料與指令都可攜帶 Mermaid 設定。本模組會保留這個開放資料負載，但不會重新定義 Mermaid 的選項、主題、安全性設定或指令語意。該結構描述請參閱官方 [Mermaid 設定文件](https://mermaid.js.org/config/configuration.html)與 [指令文件](https://mermaid.js.org/config/directives.html)。
