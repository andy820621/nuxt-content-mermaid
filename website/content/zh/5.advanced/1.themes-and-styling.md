# 主題與樣式

內建 renderer 會在每次渲染時解析 Mermaid 主題，並為外層控制項提供 CSS 變數。主題名稱影響 Mermaid SVG 輸出；`--ncm-*` 變數則影響本模組的 wrapper、工具列、overlay 與 zoom UI。

## 設定淺色與深色預設值

設定由自動 color mode 與保留手動策略選用的主題：

```ts
export default defineNuxtConfig({
  contentMermaid: {
    theme: {
      light: 'default',
      dark: 'dark',
    },
  },
})
```

預設為 `light: 'default'` 與 `dark: 'dark'`。已棄用的 `theme.useColorModeTheme` 鍵沒有作用。

## 手動控制主題

模組啟用後，`useMermaidTheme()` 是 Nuxt auto-import。它回傳 app-scoped reactive state 與方法：

```vue
<script setup lang="ts">
const {
  currentTheme,
  setMermaidTheme,
  getMermaidTheme,
  resetMermaidTheme,
} = useMermaidTheme()

function toggleDiagramTheme() {
  setMermaidTheme(currentTheme.value === 'dark' ? 'light' : 'dark')
}
</script>

<template>
  <button type="button" @click="toggleDiagramTheme">
    切換圖表主題
  </button>
</template>
```

- `currentTheme` 是包含手動模式的 reactive `Ref`。
- `setMermaidTheme(mode)` 用來設定它；`getMermaidTheme()` 回傳它。
- `resetMermaidTheme()` 等同於 `setMermaidTheme(null)`。

傳入 `null` 可回到自動選擇。請不要從套件 root import 這個 composable；Nuxt 會提供 auto-import。

## 區分策略與主題名稱

`'light'` 與 `'dark'` 是保留策略，不是一般的直接主題名稱值：

| 手動值 | 解析結果 |
| --- | --- |
| `'light'` | `contentMermaid.theme.light`，否則 Mermaid `'default'`。 |
| `'dark'` | `contentMermaid.theme.dark`，否則 Mermaid `'dark'`。 |
| 其他 Mermaid 主題名稱，例如 `'forest'`、`'neutral'` 或 `'base'` | 直接傳給 Mermaid。 |
| `null` | 移除手動覆寫。 |

```ts
setMermaidTheme('dark') // 設定的深色策略
setMermaidTheme('forest') // 直接 Mermaid 主題
setMermaidTheme(null) // 自動模式
```

## 了解主題解析規則

套件的 Theme Resolution Policy，依優先度由高至低如下：

1. 選用圖表設定來源的 `config.theme`：Markdown 頁面使用 Page Mermaid Config，Vue 元件使用 Direct Mermaid Config。
2. `useMermaidTheme()` 的手動模式。
3. 已安裝 `@nuxtjs/color-mode` 時，目前的 color-mode 值。
4. `contentMermaid.loader.init.theme`（依序 fallback 至設定的淺色主題與 `'default'`）。

自動 color-mode 選擇時，`dark` 使用 `theme.dark`；其他偵測到的 color-mode 值都使用 `theme.light`。Mermaid YAML frontmatter 與 directives 仍是 Mermaid 擁有的原始碼語法；其邊界請參閱[撰寫圖表](/zh/writing-diagrams#審慎使用-mermaid-directives)。

## 同時使用 color mode 與手動控制

有 `@nuxtjs/color-mode` 時，只要手動模式是 `null`，圖表便會跟隨它。只有檢視畫面需要覆寫時才設定手動模式，完成後重設以恢復 color-mode 選擇：

```ts
const { resetMermaidTheme, setMermaidTheme } = useMermaidTheme()

setMermaidTheme('dark')
resetMermaidTheme()
```

手動狀態是 app-scoped，因此刻意鎖定圖表主題的檢視畫面離開時，請規劃重設時機。

## 覆寫內建樣式 hooks

請在應用程式 CSS 設定變數。以下提供精簡的品牌化淺色／深色調色盤：

```css
:root {
  --ncm-code-bg: #f3f4f6;
  --ncm-code-bg-hover: #e5e7eb;
  --ncm-border-color: #d1d5db;
  --ncm-text: #111827;
  --ncm-text-muted: #4b5563;
  --ncm-text-xmuted: #6b7280;
  --ncm-overlay-bg: #f9fafb;
}

html[data-theme='dark'],
.dark {
  --ncm-code-bg: #111827;
  --ncm-code-bg-hover: #1f2937;
  --ncm-border-color: #374151;
  --ncm-text: #f9fafb;
  --ncm-text-muted: #d1d5db;
  --ncm-text-xmuted: #9ca3af;
  --ncm-overlay-bg: #111827;
}
```

### Surface、border 與 text hooks

| 變數 | 用途 |
| --- | --- |
| `--ncm-code-bg` | 圖表區塊與工具列背景。 |
| `--ncm-code-bg-hover` | 工具列與 zoom 控制項的 hover surface。 |
| `--ncm-border-color` | 邊框顏色組成。 |
| `--ncm-border-width` | 邊框寬度組成。 |
| `--ncm-border-style` | 邊框樣式組成。 |
| `--ncm-border` | 完整圖表區塊 border shorthand。 |
| `--ncm-border-bottom` | 工具列底部邊框。 |
| `--ncm-text` | 主要控制項文字。 |
| `--ncm-text-muted` | 工具列標題與次要文字。 |
| `--ncm-text-xmuted` | 工具列圖示與較淡文字。 |

### Overlay、cursor 與 hint hooks

| 變數 | 用途 |
| --- | --- |
| `--ncm-overlay-bg` | 展開 overlay 的基礎背景。 |
| `--ncm-overlay-opacity` | 可見 overlay 的不透明度。 |
| `--ncm-overlay-backdrop` | 可見 overlay 的 `backdrop-filter`。 |
| `--ncm-expand-target-bg` | `expand.margin` 留出空間時，展開圖表的背景。 |
| `--ncm-cursor-expand` | 圖表可開啟展開 overlay 時的游標。 |
| `--ncm-cursor-collapse` | 可關閉 overlay 上的游標。 |
| `--ncm-hint-bg` | zoom hint 背景。 |
| `--ncm-hint-text` | zoom hint 文字顏色。 |
| `--ncm-hint-radius` | zoom hint 圓角。 |

### Toolbar 與 zoom 版面 hooks

| 變數 | 用途 |
| --- | --- |
| `--ncm-icon-size` | renderer 計算出的基礎圖示尺寸。 |
| `--ncm-toolbar-height` | 用於定位全螢幕 zoom 控制項的計算工具列高度。 |
| `--ncm-zoom-gap` | zoom 控制項之間的空間。 |
| `--ncm-zoom-padding` | zoom toolbar padding。 |
| `--ncm-zoom-radius` | zoom toolbar 圓角。 |
| `--ncm-zoom-font-size` | zoom toolbar 字型大小。 |
| `--ncm-zoom-btn-padding` | zoom button padding。 |
| `--ncm-zoom-btn-radius` | zoom button 圓角。 |

renderer 會動態設定 `--ncm-icon-size`、`--ncm-toolbar-height` 與 cursor 變數。只有在同時考量相符的控制項尺寸與互動狀態時，才覆寫它們。
