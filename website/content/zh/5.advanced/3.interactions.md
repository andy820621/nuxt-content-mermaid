# 互動

內建 renderer 提供複製原始碼、瀏覽器全螢幕、展開 overlay 與 zoom/pan 控制項。已成功解析的[自訂 renderer](/zh/advanced/custom-rendering)會將它們全部取代，因此本頁只適用內建 renderer。

## 選擇可見的工具列控制項

工具列會顯示在每張內建圖表上方。預設會啟用標題與控制項：

```ts
export default defineNuxtConfig({
  contentMermaid: {
    toolbar: {
      title: 'Architecture',
      fontSize: '14px',
      fullscreenToolbarScale: 1.25,
      buttons: {
        copy: true,
        fullscreen: true,
        expand: true,
      },
    },
  },
})
```

`copy` 會複製 Mermaid 原始碼。嘗試後，按鈕標題與 accessible label 會暫時顯示 `Copied` 或 `Copy failed`；renderer 會先使用 Clipboard API，接著嘗試瀏覽器的 legacy copy fallback。只有瀏覽器支援 Fullscreen API 時才顯示 `fullscreen`。`expand` 會開啟頁內 overlay。

將按鈕設為 `false` 可隱藏它。隱藏 expand 按鈕不會停用點擊圖表來開啟 overlay；請用 `expand.invokeOpenOn.diagramClick` 個別控制。

## 設定開啟與關閉

預設會啟用 `expand`。其關閉控制項可分別設定：

```ts
export default defineNuxtConfig({
  contentMermaid: {
    expand: {
      margin: 24,
      invokeOpenOn: {
        diagramClick: true,
      },
      invokeCloseOn: {
        esc: true,
        wheel: true,
        swipe: true,
        overlayClick: true,
        closeButtonClick: true,
      },
    },
  },
})
```

`margin` 會在展開的 SVG 周圍保留像素空間。設定 `expand: false` 可完全停用此功能。boolean preset 與 object patch 的差異請參閱[設定](/zh/configuration#設定展開行為)。

| 控制項 | 預設值 | 效果 |
| --- | --- | --- |
| `diagramClick` | `true` | 點擊渲染後的圖表會開啟 overlay。 |
| `esc` | `true` | Escape 會關閉 overlay。 |
| `wheel` | `true` | 在 overlay 背景上未使用修飾鍵的滾輪動作會關閉它。 |
| `swipe` | `true` | 單指滑動會關閉 overlay。 |
| `overlayClick` | `true` | 點擊 overlay 背景會關閉它。 |
| `closeButtonClick` | `true` | 顯示標示「Minimize diagram」的按鈕，並讓它關閉 overlay。 |

瀏覽器全螢幕控制項依瀏覽器的一般全螢幕行為離開，不使用 expand-overlay 的關閉規則。

## 縮放與平移大型圖表

全螢幕與展開 overlay 會顯示縮小、放大、百分比與重設控制項。兩種檢視都使用相同對應：

| 輸入 | 動作 |
| --- | --- |
| Zoom 控制項 | 縮小、放大或重設。 |
| Windows/Linux 的 `Ctrl` + 滾輪，或 macOS 的 `⌘` + 滾輪 | 在指標位置縮放。 |
| `+` / `=` | 放大。 |
| `-` / `_` | 縮小。 |
| `0` | 重設 zoom 與 pan。 |
| 方向鍵 | 平移圖表。 |
| 按住 Space 並以滑鼠拖曳 | 平移圖表。 |
| 單指觸控拖曳 | 平移圖表。 |
| 雙指捏合 | 縮放圖表。 |

在展開 overlay 中，於圖表上未使用修飾鍵的滾輪不會縮放；它會顯示一次性 hint，提示使用 `Ctrl` 或 `⌘` 加上捲動。在 overlay 背景上滾輪會遵循已設定的關閉行為。pinch 是圖表操作，不會視為 swipe-to-close 手勢。

## 維持控制項可理解且可存取

內建控制項使用原生按鈕與 accessible labels，包括 Copy、Enter/Exit fullscreen、Expand/Collapse diagram、Zoom In/Out、Reset Zoom 與 Minimize diagram。鍵盤使用者可以操作控制項，並在圖表展開或全螢幕時使用 zoom 快捷鍵。

停用某個關閉路徑時，請提供另一個可觸及的關閉路徑。特別是同時關閉 `esc`、`overlayClick` 與 `closeButtonClick` 時，使用者可能沒有明顯方式離開展開檢視。取代內建 renderer 時，請在自訂元件重新實作對等的 labels、鍵盤存取、focus behavior 與 touch affordances。
