# 互動

內建渲染器提供複製原始碼、安全的 SVG／PNG 下載、瀏覽器全螢幕、展開覆蓋層與縮放／平移控制項。
已成功解析的[自訂渲染器](/zh/advanced/custom-rendering)會將它們全部取代，因此本頁只適用內建渲染器。

## 選擇可見的工具列控制項

工具列會顯示在每張內建圖表上方。預設會啟用標題與控制項：

```ts
export default defineNuxtConfig({
  contentMermaid: {
    toolbar: {
      title: 'Architecture',
      fontSize: '14px',
      fullscreenToolbarScale: 1.25,
      buttons: {
        copy: true,
        fullscreen: true,
        expand: true,
      },
      labels: {
        copy: '複製原始碼',
        copied: '已複製原始碼',
        copyFailed: '複製失敗',
        resetZoom: '重設檢視',
        download: '下載圖片',
        downloadSvg: '下載成 SVG',
        downloadPng: '下載成 PNG',
      },
    },
  },
})
```

`copy` 會複製 Mermaid 原始碼。
嘗試後，按鈕會暫時使用設定的 `copied` 或 `copyFailed` 標籤；渲染器會先使用 Clipboard API，接著嘗試瀏覽器的舊式複製備援方式。
下載控制項會另外顯示，並在直接可存取的 SVG 成功渲染後啟用；開啟後可選擇 SVG 或 PNG。只有瀏覽器支援 Fullscreen API 時才顯示 `fullscreen`。`expand` 會開啟頁內覆蓋層。

將按鈕設為 `false` 可隱藏它。隱藏 expand 按鈕不會停用點擊圖表來開啟覆蓋層；請用 `expand.invokeOpenOn.diagramClick` 個別控制。

## 自訂控制項標籤

使用 `toolbar.labels` 可在地化或重新命名內建控制項。請在 `nuxt.config.ts` 設定整個應用程式的預設標籤：

```ts
export default defineNuxtConfig({
  contentMermaid: {
    toolbar: {
      labels: {
        copy: '複製原始碼',
        copied: '已複製',
        copyFailed: '複製失敗',
        expand: '展開圖表',
        collapse: '收合圖表',
        minimize: '縮小圖表',
        enterFullscreen: '進入全螢幕',
        exitFullscreen: '離開全螢幕',
        zoomIn: '放大',
        zoomOut: '縮小',
        resetZoom: '重設縮放',
        download: '下載圖片',
        downloadSvg: '下載成 SVG',
        downloadPng: '下載成 PNG',
      },
    },
  },
})
```

此物件是部分覆寫：只需設定想變更的標籤。省略的標籤保留預設值，空字串則視為明確設定。控制項具有對應介面時，解析後的標籤會同時用於可見文字、`title` 與 `aria-label`。

Mermaid fence 可以只覆寫單一圖表的標籤，不影響應用程式預設值：

````md
```mermaid
---
toolbar:
  labels:
    copy: 複製這張圖表
    copied: 已複製圖表
    resetZoom: 重設圖表檢視
    download: 儲存圖表
    downloadSvg: 將圖表下載為 SVG
    downloadPng: 將圖表下載為 PNG
---
graph TD
  A --> B
```
````

所有標籤鍵、型別與預設值請參閱[工具列設定](/zh/configuration#工具列)。

## 下載最後一次成功的圖表

下載控制項提供「下載成 SVG」與「下載成 PNG」，來源都是內建渲染器最後一次成功提交至頁面的 SVG。仍在載入、失敗或已過期的渲染不會取代可下載版本。第一次 SVG 成功前、元件設定衝突期間，或 Mermaid sandbox 輸出只能透過 iframe 取得時，按鈕會保持停用且不產生檔案。

兩種格式都會先清理同一份 committed snapshot 的 detached clone，因此不會改動畫面中的圖表、複製狀態、展開／全螢幕檢視或縮放，也不會重新執行 Mermaid 或修改生效中的 Mermaid 設定。

- SVG 會將 snapshot 序列化為 `mermaid-diagram.svg`。它會保留 Mermaid 已渲染的結構，包括啟用 `htmlLabels` 時的 `foreignObject`，同時移除 script、嵌入式瀏覽器內容、事件屬性、連結，以及外部或危險的資源引用。若需要原生 SVG `<text>`／`<tspan>`，請在 Mermaid 設定中使用 `htmlLabels: false`；頁面與下載 SVG 會自然套用同一設定。
- PNG 會以 committed CSS-pixel 尺寸將同一份安全 snapshot 點陣化為 `mermaid-diagram.png`。除非圖表本身含有背景，透明區域會維持透明。PNG rasterizer 只會在第一次要求 PNG 時載入，之後重用；轉換期間 PNG 選項會顯示載入狀態並停用。必要 stylesheet 無法讀取、含有 CSS `@import`，或 webfont 無法嵌入時，轉換會明確失敗，不會下載使用 fallback font 的 PNG。需要的 `@font-face` 規則應直接定義，不要再匯入另一份 stylesheet。

下載選項使用原生按鈕與自然 Tab 順序：

- 在觸發按鈕按 Enter 或 Space 會開啟選項並聚焦 SVG。
- Tab 依序移動 SVG → PNG → 下一個工具列控制項，離開時關閉選項。Shift+Tab 依序移動 PNG → SVG；從 SVG 再按一次會回到觸發按鈕並關閉。
- Escape 會關閉並聚焦觸發按鈕。SVG 或 PNG 下載完成後也會關閉並把焦點移回觸發按鈕，方便重複下載。
- 點擊外部會關閉選項，不強制改變焦點。PNG 轉換進行中時，選項會維持開啟，讓載入狀態保持可見。

自訂渲染器自行負責下載行為，不會取得此控制項。

## 設定開啟與關閉

預設會啟用 `expand`。其關閉控制項可分別設定：

```ts
export default defineNuxtConfig({
  contentMermaid: {
    expand: {
      margin: 24,
      invokeOpenOn: {
        diagramClick: true,
      },
      invokeCloseOn: {
        esc: true,
        wheel: true,
        swipe: true,
        overlayClick: true,
        closeButtonClick: true,
      },
    },
  },
})
```

`margin` 會在展開的 SVG 周圍保留像素空間。設定 `expand: false` 可完全停用此功能。
布林預設組態與物件修補的差異請參閱 [設定](/zh/configuration#展開)。

完整的展開選項路徑、預設值與效果，請參閱 [展開設定](/zh/configuration#展開)。

瀏覽器全螢幕控制項依瀏覽器的一般全螢幕行為離開，不使用展開覆蓋層的關閉規則。

## 縮放與平移大型圖表

全螢幕與展開覆蓋層會顯示縮小、放大、百分比與重設控制項。兩種檢視都使用相同對應：

| 輸入 | 動作 |
| --- | --- |
| 縮放控制項 | 縮小、放大或重設。 |
| Windows/Linux 的 `Ctrl` + 滾輪，或 macOS 的 `⌘` + 滾輪 | 在指標位置縮放。 |
| `+` / `=` | 放大。 |
| `-` / `_` | 縮小。 |
| `0` | 重設縮放與平移。 |
| 方向鍵 | 平移圖表。 |
| 按住 Space 並以滑鼠拖曳 | 平移圖表。 |
| 單指觸控拖曳 | 平移圖表。 |
| 雙指捏合 | 縮放圖表。 |

在展開覆蓋層中，於圖表上未使用修飾鍵的滾輪不會縮放；它會顯示一次性提示，提示使用 `Ctrl` 或 `⌘` 加上捲動。
在覆蓋層背景上滾輪會遵循已設定的關閉行為。捏合是圖表操作，不會視為滑動關閉手勢。

## 維持控制項可理解且可存取

### 內建控制項

內建工具列控制項一律使用原生 `<button>` 元素與對應的可存取標籤，涵蓋：

- Copy
- Download SVG
- Enter/Exit fullscreen
- Expand/Collapse diagram
- Zoom In/Out
- Reset Zoom
- Minimize diagram

可透過 `toolbar.labels` 自訂各項標籤；解析後的值會視情況同時套用為可見文字、`title` 與 `aria-label`。

### 鍵盤操作

所有控制項皆可透過鍵盤操作。圖表處於展開檢視或全螢幕模式時，亦可使用縮放快捷鍵。

### 焦點（focus）管理

- 展開檢視時， focus 會移至關閉按鈕；若已停用關閉按鈕（ `closeButtonClick`）， focus 則改移至對話框本身。
- 在展開檢視的情況下，Tab 與 Shift+Tab 會將 focus 固定在 overlay 的工具列內。
- 進入全螢幕時， focus 會移至退出全螢幕按鈕。
- 關閉展開檢視或退出全螢幕後：
  - 若原本觸發的工具列控制項仍存在， focus 會回到該控制項。
  - 若該圖表或控制項已被移除，則略過 focus 還原。

::callout{variant="warning" title="可存取性提醒"}
停用任一關閉方式時，請務必保留至少一個可觸及的替代關閉路徑。
若同時停用 `esc`、`overlayClick` 與 `closeButtonClick`，使用者將沒有明顯方式離開展開檢視。

若以自訂元件取代內建渲染器，請自行重新實作對等的標籤、鍵盤操作、 focus 管理與觸控互動，以維持相同的可存取性水準。
::
